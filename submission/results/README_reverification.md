# 1D 재검증

원본 `verify_const.csv`(900001–900027), `verify_gpr.csv`(910001–910027)의 status 54/54 converged를 먼저 확인했다. id_map의 일대일 case_id→point_id 대응으로 변환한 파일을 `solver_const_mapped.csv`, `solver_gpr_mapped.csv`에 저장했다. 열적 압력은 `dp_thermal_para_Pa`, 수력 압력은 `dp_hyd_conv_Pa`를 사용한다. 과도 수력 항 `dp_hyd_para_Pa`와 혼동하지 않았다. 전체 출력과 16열 파일의 다섯 대상 압력·열침입 열은 완전히 일치했다. 입력 설계값은 솔버 CSV의 유효숫자 반올림 범위(rtol=5e-6) 내에서 원 후보와 일치했다.

`optimize.py compare --points outputs/full10k/optimization/{const,gpr}/verification_points.csv --solver outputs/full10k/reverification/solver_{const,gpr}_mapped.csv --output outputs/full10k/reverification/T4_{const,gpr}.csv`를 방식별로 실행했다. 모델을 로드하거나 학습하지 않았다. 결합 T4에는 부호·절대 오차, 예측/솔버 제약 판정 및 일치 여부를 보존했다.

| 방식 | Q_leak 평균 / 최대 오차 (%) | dp_thermal 평균 / 최대 오차 (%) | dp_design 평균 / 최대 오차 (%) | 판정 일치 |
|---|---:|---:|---:|---:|
| const | 0.001447 / 0.005976 | 0.154706 / 0.906288 | 0.931966 / 1.469167 | 27/27 |
| gpr | 0.001460 / 0.005976 | 0.152522 / 0.892604 | 0.045181 / 0.170341 | 24/27 |

54개 전체 출력의 status는 모두 converged이며, 각 방식 27점의 세 출력 모두 최대 절대오차 5% 이내입니다. 오차는 100×(예측/솔버−1), 위 평균·최대는 절대오차입니다.
const의 전체 압력 평균 부호 있는 오차는 +0.931966%, 수력 성분은 +1.015842%(평균 +238.860 Pa)입니다. 솔버 수력/강체 비율은 1.773353–1.796532(평균 1.781924)로 1.8보다 작아 보수적인 과대평가가 판정 전부 일치에 기여했습니다. 이는 항상 안전하다는 보장은 아닙니다.
GPR의 전체 압력 평균 부호 있는 오차는 −0.030725%이며, V003(S1/C), V012(S2/C), V021(S3/C)는 안전으로 예측했지만 솔버에서 각각 6.1, 18.3, 1.0 Pa 초과했습니다. 상세 값은 results/T4_mismatches.csv에 있습니다.
일정 비율의 제약 여유 등은 **재검증 결과를 보고 한 사후 제안**이며 적용·검증하지 않았습니다. 제약 48,300 Pa와 기존 최적화 결과는 유지했고 학습·최적화·최종 테스트·솔버를 다시 실행하지 않았습니다.
새 T4는 레포 compare로 전체 출력에서 계산했으며 교차 확인용 T4의 54행·모든 공통 열과 일치합니다(최대 수치 차이 0). 이 결과는 해당 54점의 1D 재검증이며 실험 검증이나 전체 설계 공간의 안전성 보장은 아닙니다.

| point_id | 시나리오 | 역할 | 예측 dp_design (Pa) | 솔버 dp_design (Pa) | 솔버 초과량 (Pa) |
|---|---|---|---:|---:|---:|

| V012 | S2 | C | 48266.930301 | 48318.3 | 18.3 |
| V021 | S3 | C | 48296.447938 | 48301.0 | 1.0 |

GPR 불일치 세 점은 모두 false safe이며 false unsafe는 0개다. const의 평균 수력 과대평가 +238.860 Pa와 열적 예측 오차가 전체 압력의 보수성을 만든다. 역할 extra는 원 후보의 표기를 그대로 보존했다.

교차 확인은 (hyd, point_id)로 54행을 일대일 정렬하여 제공 T4의 나머지 17개 열을 모두 비교했다. 모든 숫자 차이는 0, 문자열·불리언도 일치했다. 계산 결과를 제공 T4에서 복사하지 않았다. 수치 정의와 입력 해시는 audit.json, 열별 비교는 T4_crosscheck.csv에 있다.

일정 비율 여유는 사후 제안일 뿐 재최적화에 사용하지 않았다. 예측+2σ를 검토한다면 현재 저장된 σ가 log10(dp_thermal)의 불확실성이므로 이를 전체 dp_design의 Pa 표준편차처럼 더해서는 안 된다. 수력 보정 오차를 포함한 보장도 검증하지 않았다.
